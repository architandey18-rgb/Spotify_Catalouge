# Spotify Catalogue Analysis

## Project Overview

This project is based on Spotify Catalogue Data Analysis using Python and Pandas. It helps users explore popular songs, search for songs by artist name, and view song details such as popularity and danceability.

## Objectives

- To load and analyze Spotify catalogue data.
- To display the most popular songs from the dataset.
- To search songs using an artist's name.
- To display song name, popularity, and danceability.

## Technologies Used

- Python
- Pandas
- Google Colab
- CSV Dataset

## Dataset

The project uses a Spotify catalogue dataset stored in a CSV file named "dataset.csv".

The dataset contains information such as:

- Track ID
- Artist Name
- Album Name
- Track Name
- Popularity
- Duration
- Danceability

## Features

1. Display Popular Songs: The user enters how many popular songs they want to see.
2. Artist Search: The user enters an artist's name to search for their songs.
3. Song Details: Displays track name and popularity.
4. Danceability Analysis: Displays the danceability score of the searched artist's songs.

## How to Run the Project

1. Download the project repository.
2. Keep the "dataset.csv" file in the same folder as the Python notebook.
3. Open the notebook in Google Colab.
4. Run the code.
5. Enter the number of popular songs.
6. Enter an artist's name to view their songs and details.
